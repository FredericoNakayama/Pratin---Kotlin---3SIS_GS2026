# 04 — Interface (UI/UX)

A identidade visual é a mesma do Pratin em Flutter (prints de referência no repositório Flutter, pasta `docs/prints/`). O app deve "parecer o mesmo produto", mas construído com componentes nativos do Material 3 para Compose.

## 1. Identidade visual

| Item | Definição |
| --- | --- |
| Conceito | Acolhedor, confiável, ligado a comida. Verde = sustentabilidade; laranja = pão e alimento. |
| Primária | Verde `#2E7D32` (container claro `#C8E6C9`) |
| Secundária | Laranja `#F57C00` (container claro `#FFE0B2`) |
| Fundo / superfície | `#FAFAF7` / `#FFFFFF` |
| Erro | `#C62828` |
| Favorito | `#E53935` |
| Status | Disponível/Ativa `#2E7D32` · Reservado `#FFA000` · Retirado/Concluída `#1565C0` · Cancelado/Cancelada `#757575` · Expirado/Expirada `#B71C1C` |
| Tipografia | Material 3 padrão; usar `MaterialTheme.typography` (`headlineSmall`, `titleMedium`, `bodyMedium`, `labelLarge`). Código de retirada em `FontFamily.Monospace`. |
| Espaçamento | `Dimens`: 4, 8, 12, 16, 24, 32 dp. Margem lateral padrão 16 dp. |
| Formas | `Card` raio 12 dp · botões raio 10 dp · chips arredondados |
| Ícones | `Icons.Filled/Outlined/Rounded` (material-icons-extended) |
| Logo | Copiar `assets/images/logo.png` do repositório Flutter para `res/drawable/logo_pratin.png`; ícone do app (adaptive icon) com o logo sobre fundo branco. |

### Tema (`ui/theme`)
- `PratinTheme` com `lightColorScheme` montado a partir das cores acima (primary, onPrimary, primaryContainer, secondary, secondaryContainer, background, surface, error).
- **Desligar dynamic color** (o app tem identidade própria). Tema escuro: PODE existir derivado, mas os prints do README usam o tema claro.
- Cores de status e favorito em `PratinColors` (objeto) consumidas por extensões (`StatusAlimento.cor()`).

## 3. Telas

### T01 — Splash
- Fundo verde primário em tela cheia; `Column` centralizada: logo (96 dp), "Pratin" (`headlineMedium`, branco), slogan "Alimento bom não se joga fora." (`bodyLarge`, branco 85%), `CircularProgressIndicator` pequeno branco.
- Sem barra superior nem inferior.

### T02 — Onboarding
- `HorizontalPager` com 3 páginas (`OnboardingPagina`: ícone/ilustração grande em círculo `primaryContainer`, título `headlineSmall`, descrição `bodyLarge`, centralizados).
- Topo: `TextButton` "Pular" à direita (oculto na última página).
- Rodapé: indicador de bolinhas; `Row` com "Voltar" (`TextButton`, oculto na 1ª) e "Avançar"/"Começar" (`Button`).
- Última página: `Row` com `Checkbox` + "Não mostrar novamente" (linha inteira clicável, `Modifier.toggleable`).
- Ícones sugeridos: página 1 `DeleteOutline`/`NoFood`, página 2 `Storefront`, página 3 `VolunteerActivism`.

### T03 — Shell
- `Scaffold` raiz com `NavigationBar` (3 itens: Início `Home`, Atividades `ReceiptLong`, Perfil `Person`), visível só nas abas.
- Cada aba tem seu próprio `Scaffold` interno com `TopAppBar` e `SnackbarHost`.

### T04 — Início
```
┌───────────────────────────────────────┐
│ [logo] Pratin                     ⓘ  │  TopAppBar
│ Olá, Padaria Pão Quente!              │  saudação (ou "Olá!")
│ Alimentos disponíveis para doação     │
│ ┌───────────────────────────────────┐ │
│ │ 🔍 Buscar alimento             ✕ │ │  OutlinedTextField
│ └───────────────────────────────────┘ │
│ (♡ Favoritos) (✓ Todos) (Pães…) (…) → │  LazyRow de FilterChip
│ ┌───────────────────────────────────┐ │
│ │[foto] Marmita de arroz…        ♥ │ │  AlimentoCard
│ │       15 porções · Refeições     │ │
│ │       ⏰ Vence amanhã  (laranja)   │ │
│ │       Retirada 15/11 11:00–14:00  │ │
│ │       Restaurante Sabor Caseiro   │ │
│ └───────────────────────────────────┘ │
│                         [+ Anunciar]  │  ExtendedFAB (Estab./sem perfil)
└───────────────────────────────────────┘
```
- Lista: uma única `LazyVerticalGrid` dentro de `PullToRefreshBox` — 1 coluna em telas estreitas e 2 a partir de 600 dp. Saudação, busca e chips são o primeiro item (ocupando a linha inteira), então rolam junto com os cards e não tomam a tela em paisagem.
- Estados: carregando → `LoadingState`; vazio → `EmptyState` (ícone + mensagem do RF06/07/08); erro inesperado → `ErrorState` com "Tentar novamente".
- "Vence hoje/amanhã" em laranja (secundária); demais em `onSurfaceVariant`.

### T05 — Detalhes
- `TopAppBar` com seta voltar, nome (1 linha, reticências) e `FavoritoButton`.
- `Column` rolável: imagem 16:9 (`AlimentoImagem`), `StatusChip`, nome (`headlineSmall`), `Card` com `InfoRow`s: quantidade, categoria, validade (data + "Vence em…"), janela de retirada, estabelecimento, endereço.
- Selo "Doação gratuita" (`AssistChip` com `VolunteerActivism`) e texto "Declarado próprio para consumo pelo estabelecimento".
- Rodapé fixo (`bottomBar` do Scaffold): botão "Reservar" (ONG/sem perfil) ou `Card` informativo "Apenas ONGs podem reservar alimentos." (Estabelecimento) ou status quando indisponível.

### T06 — Perfil (aba) e Editar perfil (tela cheia)
- **Sem perfil ou editando:** formulário rolável: `SingleChoiceSegmentedButtonRow` (Estabelecimento / ONG; nenhum selecionado no 1º cadastro), `OutlinedTextField` nome, CNPJ (teclado numérico, máscara visual `00.000.000/0000-00` via `VisualTransformation`), endereço; `TextButton` "Preencher com perfil de demonstração" (abre `DropdownMenu` com os perfis da seed); `Button` "Salvar perfil". Erros com `isError` + `supportingText`.
- **Com perfil:** `Card` resumo (ícone do tipo, nome, CNPJ formatado, endereço, tipo); `OutlinedButton` "Editar perfil"; `TextButton` "Sobre o Pratin"; `TextButton` "Ver introdução novamente".
- `EditarPerfilRoute` reaproveita o mesmo formulário, com seta de voltar, e faz `popBackStack()` ao salvar.

### T07 — Novo anúncio
- `TopAppBar` "Novo anúncio" com voltar. Formulário rolável (`verticalScroll` + `imePadding`):
  1. Nome (`OutlinedTextField`, contador 0/60)
  2. Categoria (`ExposedDropdownMenuBox`)
  3. `Row`: Quantidade (teclado decimal) + Unidade (dropdown)
  4. Data de validade (`DateField` → `DatePickerDialog`, datas selecionáveis de hoje a hoje+7)
  5. Início da retirada e Fim da retirada (`DateTimeField` → `DatePickerDialog` + diálogo com `TimePicker` 24 h)
  6. Endereço (pré-preenchido com o do perfil)
  7. URL da foto (opcional) + pré-visualização com `AlimentoImagem` quando preenchida
  8. `Checkbox` "Declaro que o alimento está próprio para consumo"
  9. `PrimaryButton` "Publicar anúncio" (com progresso)
- Erros por campo (`supportingText`); erro geral em Snackbar.
- ⚠️ `DatePickerState.selectedDateMillis` está em **UTC**: converta com `Instant.ofEpochMilli(ms).atZone(ZoneOffset.UTC).toLocalDate()`. Limite datas com `SelectableDates`.

### T08 — Confirmação de reserva
- Ícone `CheckCircle` grande verde, "Reserva confirmada!", `CodigoRetiradaBox` (código grande, monoespaçado, letras espaçadas, fundo `primaryContainer`, botão copiar), `Card` com alimento, estabelecimento, endereço e janela, aviso "Apresente este código ao estabelecimento na retirada.", `Button` "Ver minhas atividades", `TextButton` "Voltar ao início".
- Sem seta de voltar; "voltar" do sistema leva ao Início.

### T09 — Minhas atividades
- Título muda por perfil: "Minhas reservas" (ONG) ou "Meus anúncios" (Estabelecimento). Lista em `PullToRefreshBox`.
- **ONG — `ReservaCard`:** nome do alimento, `StatusChip`, `CodigoRetiradaBox` compacto (só se ATIVA), janela, estabelecimento, endereço, `OutlinedButton` "Cancelar reserva" (se permitido).
- **Estabelecimento — `AnuncioCard`:** miniatura, nome, `StatusChip`, quantidade, janela, "Reservado por ONG X" (se reservado), ações: `OutlinedButton` "Cancelar anúncio" (DISPONIVEL) ou `Button` "Confirmar retirada" (RESERVADO e janela aberta).
- Sem perfil: `EmptyState` + botão "Configurar perfil" (vai à aba Perfil).

### T10 — Sobre o Pratin
- `TopAppBar` "Sobre o Pratin" com voltar. `Column` rolável com: logo + slogan; seções em `Card`: "O problema", "Quem é beneficiado", "Como funciona" (3 passos numerados), "Objetivos de Desenvolvimento Sustentável" (ODS 2 e ODS 12, cada um com 1 frase), "Sobre este protótipo" (acadêmico, dados locais de exemplo, sem integração com serviços externos), equipe (nomes e RMs).

## 7. Acessibilidade e responsividade
- Áreas de toque ≥ 48 dp; `contentDescription` em `IconButton`s e imagens informativas (`null` em ícones decorativos).
- Linhas com checkbox/switch inteiras clicáveis (`toggleable` + `Role.Checkbox`).
- Edge-to-edge: respeitar `WindowInsets` (o `Scaffold` já trata; formulários com `imePadding()`).
- Textos com `maxLines` + `TextOverflow.Ellipsis` nos cards.
- Grade de 2 colunas a partir de 600 dp (`LocalConfiguration`/`BoxWithConstraints`).
